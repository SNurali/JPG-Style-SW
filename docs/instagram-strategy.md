## 6. Идеи коллабораций с мойками

### Форматы сотрудничества

#### 1. Бартер: продукция → контент
- Мойка получает продукцию SmartWash бесплатно
- Взамен: мойка снимает Reels с использованием химии (до/после, процесс)
- Условие: упоминание @smartwash.uz в посте и Stories

**Пример:** "Мойка X" использует SmartWash → снимаем видео Pink Panther в работе → делим Reel на страницах обоих брендов

#### 2. Giveaway на мойке (кросс-промо)
- Приз: набор SmartWash + сертификат на мойку от партнёра
- Условия: подписка на оба аккаунта, отметка друга, репост Stories
- Частота: 1 раз в 2 недели

#### 3. "Мойка месяца" — ежемесячная рубрика
- Выбираем одну автомойку, которая использует SmartWash
- Снимаем полноценный обзор: интервью с владельцем, процесс мойки, результат
- Публикуем Reel + Carousel на странице SmartWash и мойки

#### 4. Оптовая программа для моек (B2B)
- Специальные условия для автомоек: цена + мерч + упоминание
- При заказе от 3 единиц — съёмка Reels на мойке бесплатно
- Мойка получает статус "Официальный партнёр SmartWash"

#### 5. Скидка для клиентов партнёра
- Клиенты мойки получают скидку 10% на продукцию SmartWash
- Клиенты SmartWash получают скидку на мойку у партнёра
- Продвигается через Stories обоих брендов

### Целевые мойки для коллаборации (примеры для Ташкента)
- Крупные бесконтактные мойки в Сергели, Чиланзаре, Юнусабаде
- Детейлинг-центры с премиум-позиционированием
